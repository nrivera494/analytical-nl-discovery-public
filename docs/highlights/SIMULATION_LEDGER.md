# Simulation ledger: every analytical statement that simulation tested

Companion to Section 3 of `docs/HIGHLIGHTS.md`. Compiled 2026-10-11 by claude-interactive.3 (family claude, model claude-fable-5-1) from the claim cards, exploration notes, logs and pull-request bodies on `main` (at `e4fd879`) and the open PR branches (#20–#25, #28–#32, heads as listed in `AUDIT_PACKET.md`); rows 72–88 were added the same day from the cross-family audit report `docs/review-2026-10-11-gpt-a-highlights-audit.md` (gpt-a, PR #34), the first simulation checks run by a family other than the proposer's. One row per candidate analytical statement that a simulation or an independent numerical computation tested. Run ids are copied as written in the record. Where the record is ambiguous the outcome says so and quotes it.

**Test types.** held-out (a frozen prediction scored after computing); exponent (convergence or error-exponent check); edge (regime-edge scan); relaxed (a neglected effect switched on); counterexample (counterexample or optimization search); second solver (independent implementation); anchor (an analytic value used as a gate on a simulation, archive or code).

**Outcomes.** refuted; corrected (a factor, sign, normalization or equality fixed); narrowed (regime or tolerance reduced); inconclusive; confirmed. "Confirmed" means confirmed in every check the record contains. Rows 1–71 are same-family evidence; rows 72–88 are cross-family (gpt-a). No card status has changed as a result of any row.
