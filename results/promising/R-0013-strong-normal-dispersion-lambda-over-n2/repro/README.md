# Reproducing R-0013

All paths are relative to the repository root.

## Figure 1 (GPT 6 Pro's verification figure)

`figures/fig1-strong-dispersion-verification.png` is page 1 of the committed PDF, rendered with Ghostscript 10.07.0:

    gs -q -dNOPAUSE -dBATCH -sDEVICE=png16m -r110 -dFirstPage=1 -dLastPage=1 \
      -sOutputFile=results/promising/R-0013-strong-normal-dispersion-lambda-over-n2/figures/fig1-strong-dispersion-verification.png \
      runs/2026-10-18-pi-chatgpt-independent-verification/archive/strong/strong_comparison.pdf

**Regenerating the PDF from computation (G7, open).** `archive/strong/build_summary.py` reads the committed per-case JSON files and `hydro_n441*.json`. Its mode panels also need companion `.npz` arrays that are kept at the run's `raw_location`, so it fails on the committed files alone; this was checked on 2026-10-19 in a scratch copy. On a copy of the archive, the commands in `archive/strong/README.md` regenerate everything:

    cp -R runs/2026-10-18-pi-chatgpt-independent-verification/archive /tmp/verification
    cd /tmp/verification/strong
    export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
    python verify_strong.py --N 10 --Z 0.75 --n 256 --steps 300 --dense --out N10_Z075_n256_s300.json
    python verify_strong.py --N 20 --Z 0.75 --n 256 --steps 300 --out N20_Z075_n256_s300.json
    python verify_strong.py --N 40 --Z 0.75 --n 512 --steps 600 --out N40_Z075_n512_s600.json
    python verify_strong.py --N 10 --Z 1.5 --n 256 --steps 300 --dense --out N10_Z150_n256_s300.json
    python verify_strong.py --N 20 --Z 1.5 --n 512 --steps 600 --out N20_Z150_n512_s600.json
    python verify_strong.py --N 40 --Z 1.5 --n 1024 --steps 1200 --out N40_Z150_n1024_s1200.json
    python verify_strong.py --N 20 --Z 1.5 --n 1024 --window 16 --steps 1200 --out N20_Z150_n1024_w16_s1200.json
    python verify_strong.py --N 20 --Z 1.5 --n 1024 --window 32 --steps 1200 --out N20_Z150_n1024_w32_s1200.json
    python verify_hydro.py --n 225 --out hydro_n225.json
    python verify_hydro.py --n 441 --out hydro_n441.json
    python verify_weak_cross.py
    MPLCONFIGDIR=/tmp/mpl python build_summary.py

The Hermite-bias file `hydro_n441_w32_basis.json` is regenerated by the short Python snippet in `archive/strong/README.md`. None of this has been run end to end outside the verifier's session (task T-20261019-claude-interactive.17-01). Only `verify_weak_cross.py` was rerun on a second platform (run `2026-10-19-claude-interactive-gpt6pro-quick-repro`).
