# Reproducing R-0001

All commands run from the repository root.

1. **The Lean proofs and the formal audit.** This rebuilds the library, re-checks it with `leanchecker` and nanoda, runs the held-out certificates and the negative control, and evaluates the Gaussian ceiling. It needs elan with `leanprover/lean4:v4.35.0-rc4`, about 6 GB of disk for the Mathlib cache, about 3 GB of memory, and about 5 minutes once the cache is present.

   ```sh
   PYTHON=/path/to/python-with-mpmath bash runs/2026-10-18-claude-interactive-zs-lean-audit/run.sh
   ```

2. **The figure** (`runs/2026-10-18-claude-interactive.9-mask-adversary/fig_summary.png`). The adversarial mask searches and the figure are regenerated by the scripts in that run folder. `run_adversary.py` produces the per-case JSON files and `make_figure.py` draws the figure; see its `config.yaml` for the cases and grids. Solver checks are in `runs/2026-10-18-claude-interactive.9-zs-solver-validation/`.

3. **The relaxed-assumption check** (Raman). Run `runs/2026-10-18-claude-interactive.9-raman-escape/propagate.jl` with the agents' solver at commit b9fa957, then `analyse.py`.
