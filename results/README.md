# Results

Two tiers, one folder each (rules in [`docs/PROMOTION.md`](../docs/PROMOTION.md)):

- [`formalized/`](formalized/): sub-results whose mathematical statement is a kernel-checked Lean theorem in [`formal/`](../formal/), audited by a family other than the formalizer's.
- [`promising/`](promising/): cross-family verified and approved by the PI, but not formalized.

One folder per result, `R-NNNN-short-name/`, copied from [`_TEMPLATE/`](_TEMPLATE/); ids are sequential across both tiers. Only a pull request approved by the PI adds a folder here. `RANKING.md` is generated.
