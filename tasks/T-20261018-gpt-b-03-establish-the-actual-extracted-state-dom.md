## Goal

Determine when an extracted GRIN condensate satisfies the displaced-thermal conditions used in the narrowed direct-Kerr claim. Coherence collapse is not Fock diagonality, and super-Poissonian counts are not a coherent-mixture certificate. A nonnegative Glauber–Sudarshan P certificate is sufficient for the coherent-shot interpretation, but is not necessary for the number-conserving bright-reference Sagnac measurement: that circuit depends on the pump's number probabilities. Test anisotropic/non-Gaussian inputs and reference imperfections, including loss, using the actual extracted state. Complete a primary-source search for the mixed nu^(4/3) coefficient and the precise epsilon^2 pump-noise term; coherent Kerr and interferometric squeezing are already published. Do not promote a new universal state classification without frozen independent verification.
