## Goal

With FastDifferentiableMMNLO and an SMF-28 (or HNLF) dispersion profile at 1550 nm, recompute eps(N, T0) for N = 3-6 near T0* and at T0 = 100 fs; measure the leading soliton's photon-number fraction (self-steepening is built in). Report how far the peak position and value move from the soliton-unit law.

## Context

## Deliverables
